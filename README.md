Saathi – Mentorship App

📌 Problem

Students after 12th often lack proper guidance to choose the right career path. Due to limited access to experienced mentors, they make uninformed decisions.

💡 Solution

Saathi is a mentorship platform that connects students with verified mentors across domains like education, career, health, and safety.

✨ Features

- Category selection (Study, Safety, Health, Jobs)
- Mentor listing
- Mentor profile view
- Ask doubt feature

🎨 Tools Used

- Figma (UI/UX Design)
